Conectar la bodega a la nube

Crea la base compartida en Firebase y comprueba que el celular y el dashboard se hablan.

1

Crear el proyecto en Firebase

Esto solo lo puedes hacer tú: hay que iniciar sesión con tu cuenta de Google. Son cuatro pantallas.

  1. Entra a console.firebase.google.com → Crear un proyecto → nómbralo bodega-quinta. Puedes desactivar Google Analytics.
  2. Menú lateral → Firestore Database → Crear base de datos → modo producción → ubicación southamerica-east1.
  3. Menú lateral → Authentication → Comenzar → pestaña Sign-in method → habilita Anónimo.
    Sin este paso nada escribe: los operarios entran sin usuario y sin contraseña, pero Firebase igual les da una identidad interna para poder aplicar las reglas.
  4. Rueda dentada ⚙ → Configuración del proyecto → baja hasta Tus apps → icono </> (Web) → registra la app. Te muestra un bloque de código: cópialo entero, es lo que pegas abajo.
2

Pegar las reglas de seguridad

En Firebase → Firestore Database → pestaña Reglas: borra lo que haya, pega esto y presiona Publicar.

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    function auth() { return request.auth != null; }

    match /inventario/{doc}  { allow read, write: if auth(); }
    match /posiciones/{ubic} { allow read, write: if auth(); }

    match /movimientos/{doc} {
      allow read, create: if auth();
      allow update, delete: if false;
    }
  }
}
Si dejas las reglas de prueba que Firebase pone por defecto, en 30 días la base deja de aceptar escrituras y la app empieza a fallar sin avisar. Publica estas.
3

Pegar la configuración

Pega aquí el bloque completo que te dio Firebase en el paso 1.4. No hace falta limpiarlo.

Estos tres datos no son secretos. Van dentro de cualquier página web y cualquiera que abra tu sitio los puede ver — lo que protege la base son las reglas del paso 2, no ocultar la clave. Por eso me los puedes pasar sin problema. Lo que nunca debes compartir ni pegar aquí es la contraseña de tu cuenta de Google, un token de GitHub ni el archivo de cuenta de servicio que Firebase ofrece en la pestaña «Cuentas de servicio»: ese último sí abre la base entera y se salta las reglas.
